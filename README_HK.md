# Модель Хегсельманна–Краузе: запуск и результаты

## Что реализовано

Скрипт `hk_opinion_dynamics.py` реализует **сетевой вариант** модели Хегсельманна–Краузе. На каждом шаге агент усредняет своё мнение и мнения соседей по исходному неориентированному графу, если абсолютная разность мнений не превышает радиус доверия `epsilon`.

Скрипт выполняет серию экспериментов для:
- полного графа;
- случайного графа Эрдёша–Реньи;
- регулярной кольцевой решётки.

## Установка библиотек

```bash
python -m pip install -r requirements_hk.txt
```

## Запуск

```bash
python hk_opinion_dynamics.py --output hk_results
```

При необходимости можно изменить количество агентов и параметры:

```bash
python hk_opinion_dynamics.py --n 100 --eps-points 51 --epsilon-demo 0.25 --max-iter 5000 --output hk_results
```

## Файлы результатов

- `opinion_trajectories.png` — траектории мнений агентов в демонстрационном запуске.
- `clusters_by_epsilon.png` — число итоговых кластеров в зависимости от радиуса доверия.
- `iterations_by_epsilon.png` — число итераций до критерия сходимости.
- `experiment_summary.csv` — результаты всех запусков в табличном виде.
- `opinion_trajectories.csv` — численные данные для графика траекторий.
- `experiment_config.json` — параметры эксперимента и сведения о графах.

## Важные определения

Критерий остановки симуляции:

`max(abs(x_new - x_old)) < tol`

Число кластеров оценивается после сортировки финальных мнений: новый кластер начинается, если промежуток между соседними значениями больше `cluster_tol`. Поэтому `cluster_tol` (по умолчанию `1e-3`) — численный допуск для подсчёта кластеров, а не радиус доверия модели.

Если за `max_iter` шагов критерий сходимости не выполнен, запуск отмечается как `converged = False`; число итераций в этом случае нельзя интерпретировать как доказанное время сходимости.

## Ограничение модели

Это расширение классической модели Хегсельманна–Краузе: исходный граф ограничивает пары агентов, которые потенциально могут взаимодействовать. На полном графе реализуется классический вариант с ограниченным доверием. В экспериментах с другими топологиями влияние одновременно зависит от структуры графа и радиуса доверия.
